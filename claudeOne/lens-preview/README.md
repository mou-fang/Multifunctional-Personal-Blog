# 原首页 1:1 Lens 测试页

启动仓库现有服务后打开 `/lens-preview/#/home`（默认端口示例：`http://localhost:3001/lens-preview/#/home`）。必须通过 HTTP 打开。此目录是独立入口，尚未替换正式网站。

## 页面保持原样

首页模板、页头、页脚、播放器标记和助手容器直接取自 `../index.html`，加载正式站同一组布局样式。文案、字体、位置、尺寸、断点、魔方和访问统计卡片保持原样；没有额外的演示面板、调参按钮或新内容。导航的其他栏目在新标签页打开正式站，本页只挂载首页。

播放器、助手与外壳使用完整原脚本副本，仅将 `claudeOne:` 存储键改为 `claudeOne:lens-preview:`。启动逻辑修正子目录中的媒体及资源地址。魔方直接加载原脚本。`SOURCE.json` 记录复制来源摘要；回归测试会检查这些界面及脚本是否继续保持一致。

## 材质与动画对应

| 原有元素 | Lens 接入 |
| --- | --- |
| 导航、按钮、标签、卡片 | WebGL2 折射、色散、边缘反光与厚度；交互按钮弹性按压、拉伸、边缘滞后、释放回弹 |
| 顶部导航 | 原尺寸选中层，拖动形变、最近栏目吸附及回弹；链接原有点击、键盘操作仍可用 |
| 原主题开关 | 拖动滑块、伸缩形变、过中点切换及吸附；原复选框保留键盘控制 |
| 原音乐播放器 | 展开/收起由 Lens 弹簧驱动：容器伸展、圆角变化、速度驱动的边缘滞后/回弹和流光；封面、按钮连续换位，新增内容分阶段显现；保留原播放/暂停、上/下一首和播放模式；进度条折射、波动和结束流光，音量滑钮弹性跟随 |
| 原 AI 助手 | 原展开/收起、拖动/缩放、模型和对话菜单；菜单及消息玻璃材质、消息光学入场、选中凝实/流光、操作按钮弹性反馈 |
| 原魔方 | 原转面、打乱、还原、聚合/散开及视角拖动；控制区和按钮换用 Lens 材质及反馈 |

没有首页对应元素的图表、二维参数、轮播和自由悬浮透镜不添加到界面。Lens 画布及选中层均脱离排版；不引入上游组件样式，避免覆盖现有布局。深色主操作底色保留，保证白色文字可读。

默认材质针对浅色网格调整为通透厚玻璃（折射 100%、雾化 2.5%、色散 75%），面板、按钮和标签采用上游透镜的低填充光学表面。网格增加明暗对比，使边缘的真实折射可见；细薄的接触反光保持浅底上的轮廓。上游快照保持原样，弹性和光学效果沿用 Lens；本目录的合成与采样优化见下文。

播放器的独立表现层为 `player-motion.js`、`player-motion-core.js`、`player-motion.css`。原播放器脚本仍完整保留；两端的位置、尺寸、内容由原 CSS 实时测量，动画期间临时定位原控件，结束后移除全部尺寸和字体覆盖。快速反向切换保留弹簧速度；切换主题、调整窗口、进入后台和销毁会归位并清理。播放状态、音频时间、音量和播放器事件仍由原脚本管理。

## 性能与定位修复

`renderer-performance.js` 只在独立预览中适配固定版本的渲染器，不修改正式站或上游快照。

- 每帧首次复制完整背景，后续透镜只同步上一个透镜改动的区域；重叠透镜仍读取完整的累积图像，避免每个小按钮都复制全屏。
- 播放器按完整动画路径预留画布，展开、收起和反向切换复用同一组纹理。其他浮层按 64 像素分块增长。分配和重绘在同一帧完成，避免黑色空帧。
- 网格在显卡中按屏幕坐标生成，移动浮层只更新坐标，不再逐帧创建背景图片或上传纹理。玻璃像素比例最高为 1，大屏按约 160 万像素预算缩放；文字和控件仍使用原生 DOM 分辨率。
- `lens-shader.js` 是上游 MIT 光学片段的明确派生版：只有小于半个 CSS 像素的模糊采用硬件双线性采样，较强模糊保留九点采样。折射、色散、高光、形变、流光和进度波动计算保留。
- 播放器动画独占其玻璃重绘时机，图标和玻璃同帧更新；音量滑块不再每帧重复测量。不可见或透明控件不绘制，鼠标离开玻璃控件后不持续重绘全屏。
- 播放器使用 `overflow: clip` 防止浏览器为聚焦按钮自动滚动内部内容；动画结束清零旧滚动偏移。修复缩放后按钮整排偏移和封面裁切的问题，保留键盘焦点。
- 不超过 520px 时，展开播放器的控制条可单独横向滚动，以原按钮尺寸访问音量与收起键；聚焦时只滚动该控制条，不移动封面、播放器或玻璃背景。

各画布的 `data-lens-allocations`、`data-lens-frames` 等只读属性及 `LensPreview.snapshot()` 可检查分配与绘制工作量。调试统计不作为显卡基准或流畅度承诺。

## 状态、兼容与边界

- Soft UI 保留原主题；播放器使用同一套连续过渡，阻尼更高、回弹更克制。Liquid Glass 额外显示玻璃边缘形变和流光。
- 播放器读取同一站点歌单，继续使用原导入和播放逻辑；没有添加试听曲目、音频上传接口或新的播放器控件。
- 助手沿用原 DeepSeek 客户端、Key 设置、对话和工具流程；联网问答及 AI 自动操作需要有效 API Key。本次没有提供或验证真实 Key。
- 测试页只读取 `/api/visitors`，不发送统计心跳。状态文字随真人交互更新，测试交互不会增加正式计数。
- 测试页的主题、播放记录、助手配置和对话使用独立存储键；不读取正式助手的 API Key。
- 系统减少动态偏好会减弱弹性并关闭持续光学波动。后台停止渲染；退出时清理 Lens 监听、观察器、定时器和渲染器。原控件的交互行为保持不变。
- WebGL2 不可用时保留原 CSS 玻璃及语义控件，弹性反馈仍可用。`?render=css` 可检查此分支；不具有真实折射。
- Lens 折射的是其画布中的网格与玻璃，并非任意 DOM、文字、音乐封面或魔方画面。前景播放器、助手和弹窗使用独立画布，避免材质穿透文本。

仅供独立比较的 URL 参数：`?baseline` 关闭 Lens 与播放器新表现层；`?material=clear|soft|thick` 选择上游材质；`?motion=off` 关闭播放器形变、减弱手势并停止新增的持续光学波动。系统减少动态偏好也会直接切换播放器状态。参数不添加可见界面。

## 验证与维护

在仓库根目录运行 `npm.cmd --prefix claudeOne/server test`。`lens-preview.test.js` 检查原样模板、布局样式、完整副本、子目录资源及第三方来源摘要。浏览器检查需在相同视口、相同主题和相同交互状态下比较坐标；播放记录不同会使进度滑块位置不同，魔方聚散期间的控件位移也属于原有动画。

`lens-player-motion.test.js` 检查原布局两端、窄屏边界、内容入场、快速反向、低帧率、Soft UI 阻尼和表现层清理；事件生命周期使用离线 DOM 样例，不能替代浏览器中的动画画面验收。

`lens-performance.test.js` 检查完整播放器轨迹只分配一次、视口变化重建、重叠透镜像素一致性、局部复制工作量和分数像素边界；这些是工作量与正确性验证，不是浏览器 FPS 测量。
