# Local font assets

Original, unmodified Google Fonts WOFF2 variable subsets, retrieved 2026-10-05. Manrope v20 (400–800) and Sora v17 (500–800) preserve the existing families, weights, and Unicode ranges. The stylesheet uses `font-display: swap`.

Source stylesheet: [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&family=Sora:wght@500..800&display=swap). Families are distributed under SIL Open Font License 1.1; see [Manrope license](MANROPE-OFL.txt) and [Sora license](SORA-OFL.txt). Upstream sources: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) and [Sora](https://github.com/google/fonts/tree/main/ofl/sora).

These files live in a versioned directory because the server caches `libs/` for one year. Replace the directory and update `css/fonts.css` when upgrading fonts. No font binaries were modified.
