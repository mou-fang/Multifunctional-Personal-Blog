## 混色范围

- BT 笔涂纯色 180 条、BTSY 11 条，共 191 个笔涂色号；其中 168 色有瓶照参考值可参与估算，其余仅列资料。
- SM 喷涂纯色 24 色使用商品色卡参考值，可单独估算。
- BT 与 BTSY 在同一笔涂组中计算，组别依据 Sugo 的系列使用指南；这是计算范围约定，不是本站完成了产品化学相容性测试。SM 喷涂与笔涂组分开，也不能和其他品牌合并一份配方。
- 金属、珠光、闪金、荧光、透明、补土、保护漆、渗线色均不参与当前普通遮盖颜料模型。即使现实中能混合，也不能用这个模型预测其角度、闪光、透明叠涂或荧光表现。
- 估算使用 Spectral.js 的光谱模型，结果与 ΔE00 只表示这些参考值在模型中的差异。百分比是模拟参数，没有每色着色力/固含量和质量标定，因此不输出克数，也不能改称“滴数”。

## 获得有实测依据的质量配方

工具中的“下载酋长大陆测量模板”预填所选笔涂组的 191 个真实色号（以 BT2006 为基准白），或 SM 喷涂 24 色（以 SM5011 为基准白）。每色保留纯色和 1:1 / 1:4 白色混合的空光谱数组，还保留单独试调的验证样本。空数组不会自动变成标定参数，缺少测量时导入会报错。

填入同批次、底材、遮盖、干燥条件与仪器几何下的实际反射率及称量比例后，工具拟合质量 K/S，保留品牌、色号与原目录映射。每库上限 250 色。仪器网格须覆盖 381.2148–719.8746 nm，反射率为 0–1。

独立验证使用另外配制且未参与拟合的比例；从测量模板拟合时，复用已知拟合比例或纯色会拒绝。直接导入外部 K/S 库时，本站不知道原拟合样本，独立性仍由数据提供者声明。根据验证光谱重新计算每个样本、平均和最大 CIEDE2000 误差及光谱 RMSE，不信任导入文件手填的误差报告。批次、底材、干燥、仪器和几何条件随标定库备份保留。只验证提供的那些样本，不从样本误差推导全色域保证；也不核验用户的仪器、批次或操作。未提供独立样本时，始终显示“实物误差尚未验证”。
