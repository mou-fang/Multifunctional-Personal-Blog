# 无眠疆域 · 持续世界联机增量策略游戏方案

版本：构思第一版，2026-10-04。

状态：玩法与世界观提案，尚未接入网站，不代表已实现功能。本文中的时间、资源数值、人数和阈值均为原型初值，需要通过模拟与真人试玩调整；没有进行容量或平衡实测。

## 1. 游戏定位与必须保留的想法

所有玩家进入同一个有边界、持续运行的大陆。每位玩家建立一个国家，通过建设、自动生产和战争扩大领土。玩家离线后，服务器上的执政官 AI 继续执行其方针。独立 AI 国家也参与发展与战争。

核心体验：领地不断成长，邻国不断变化，每次回来都能看到自己此前决定的后果。

必须保留：

- 单一共享世界，玩家能在同一地图上找到彼此，不能用独立房间伪装成全局战场。
- 地图有限；随着近期活跃国家的增加，逐步开放相邻区域。
- 出生点接近其他国家，同时保留短暂的独立发展空间。
- 增量建设与领土战争互相推动。
- 人类国家有托管 AI；独立 AI 国家也实际占地。
- 战争可以吞并领土和消灭国家，但玩家有重新加入世界的路径。
- 世界延续，领土不会因为周榜结算而统一清空。

操作定位：以点选地图、下达命令、安排建设和调整方针为主。玩家不需要逐个操纵士兵；战斗也不按点击次数结算。适合一次认真经营十几分钟，再回来查看变化。

## 2. 世界观：灯塔协议

旧文明崩溃后，灰潮大陆的大部分区域被电磁风暴覆盖。幸存的城市依靠古代灯塔维持通信、生产和防御。

每座灯塔保存着一位“执政官”：它能经营城市，却不能摆脱原有协议制定新的政治目标。玩家是重新接管灯塔的人类领主。领主提供战略，执政官负责执行，国家因此不会在领主离开时停止运转。

部分灯塔失去了人类领主，形成自治国家。它们沿用旧时代不同的协议，有的重视防守，有的扩张领地，有的掠夺边疆。

“界网”是所有灯塔组成的通信网络。更多国家建立并恢复连接后，界网逐步开放风暴边缘的新区域。新区域已有地形、遗迹和自治势力，并非突然出现的一块空白土地。

灯塔协议保障基本的建国机会，却不能阻止国家之间的战争。玩家争夺的不只是面积，还包括适合建设的土地、交通瓶颈和古代信标。

世界叙事随地图变化自然产生：某个国家守住山口，另一个国家切断交通；昔日强国分裂成自治领，新领主在其废墟附近建立国家。系统把这些事件记入世界史册。

名称：游戏暂称“无眠疆域”；大陆称“灰潮大陆”；国家核心称“灯塔”；托管 AI 称“执政官”；地图外缘称“灰潮边界”。

## 3. 玩家究竟在做什么

核心循环：

> 建设城镇 → 获得金币 → 招募并维护军队 → 占领相邻地区 → 调整发展和防守 → 争夺更有价值的领土。

金币主要用于建筑、升级、招募和维护。兵力既能争夺领土，也必须留在关键地区保护生产。土地数量提供发展空间，建设和交通决定这些土地能否真正转化为实力。

玩家持续做三个决定：

1. 此刻把金币花在生产、招募还是防御？
2. 把有限兵力部署在哪条边境，愿意为哪块土地承受损失？
3. 离开时给执政官哪些权限，以及哪些明确限制？

规模较大后，重点从“再占一格”转向“让多条战线和多个城市正常运转”。界面依然保留少量主要操作，复杂度通过地图局势增加。

## 4. 一次开局的具体过程

游客可以直接观战。点击“建立领地”，填写或使用随机国名与旗帜，生成可恢复的领主身份，进入自己的出生区域。

一个领主身份同时只能有一个存续国家。跨设备恢复方式必须在正式发布前实现；单纯用浏览器存档无法保证国家可恢复。游客凭证不能视为真人身份验证。

### 开局原型初值

| 内容 | 初值 |
| --- | --- |
| 初始领土 | 首都及其周围六格，共七格 |
| 已有建筑 | 首都、一座一级城镇、一座一级兵营 |
| 金币 | 250 |
| 总兵力 | 120，分布在首都与邻近兵营 |
| 新手保护 | 最长 10 分钟，不因重连或换设备刷新 |
| 邻近目标 | 空地、弱小自治领、至少一个可争夺方向 |

新手保护同时限制双方：别人不能攻打受保护领地，受保护国家也不能攻击玩家、参加针对玩家的围攻或占领公共信标。保护期结束前明确显示剩余时间。主动提前结束需要明确操作，并有短暂过渡，不能瞬间出兵偷袭。

### 前十五分钟的体验目标

| 大致时间 | 玩家行为 | 获得的理解 |
| --- | --- | --- |
| 0–2 分钟 | 点选一块自己的空地，建造城镇；查看金币增长 | 土地需要经营，建设提高产出 |
| 2–5 分钟 | 调集部队，攻占相邻空地或弱小 AI 地区 | 兵力不能瞬移，战争存在投入 |
| 5–10 分钟 | 看见邻国接近；补充驻军，选择一个重点方向 | 扩张会形成新边境 |
| 10–15 分钟 | 保护结束；争夺山口、城镇或信标附近地区 | 局部实力和地形比国家总面积更直接 |

这是节奏目标，不保证每位玩家在固定分钟进入战斗。出生算法必须避免“十分钟后必定被老玩家消灭”的安排。

## 5. 地图、土地与建筑

地图采用二维六边形格。拖动、缩放、点选和长按都能完成主要操作；玩家看到的是领土、驻军、建筑、行军与战线，不需要管理大量独立士兵模型。

### 地形

| 地形 | 主要作用 |
| --- | --- |
| 平原 | 建设便宜，移动较快，适合经济发展 |
| 林地 | 行军较慢，有一定防守优势 |
| 丘陵 | 易守难攻，可形成交通瓶颈 |
| 遗迹 | 固定的高价值地区，包括公共信标 |
| 灰潮区 | 尚未开放，不能行军、建国或获得产出 |

第一版使用一种通用兵力，不加入复杂的兵种克制、装备和英雄养成。

### 建筑

每格最多一座主建筑；首都为特殊城市。普通建筑最高五级，升级成本递增，不允许无限叠加等级。

| 建筑 | 用途 | 取舍 |
| --- | --- | --- |
| 首都灯塔 | 基础产出、招募、治理与身份核心 | 需要集中保护，不能无限复制 |
| 城镇 | 金币产出与储备容量 | 经济强，但不能替代军队 |
| 兵营 | 招募速度与可维持兵力上限 | 招募持续消耗金币 |
| 要塞 | 提高驻军的防守与容纳能力 | 无人驻守时作用有限，主要消耗而非生产 |

升级以建筑功能变化为主：更高产出、更大容量、更好的要塞。军事质量加成总幅度应有明确上限，不能使老玩家一名士兵抵得上新玩家几百名。

金币达到储备上限后停止积累；军队达到维持上限后停止招募。执政官可以按预算进行建设，避免离线只剩满仓等待。

### 经济原型初值

| 项目 | 初值 |
| --- | --- |
| 首都金币产出 | 60 / 分钟 |
| 一级城镇金币产出 | 15 / 分钟 |
| 首都招募 | 最多 6 兵 / 分钟 |
| 一级兵营招募 | 最多 12 兵 / 分钟 |
| 单位招募成本 | 1 金币 / 兵 |
| 普通兵力维护 | 0.05 金币 / 兵 / 分钟 |
| 非首都领土基础维护 | 0.5 金币 / 格 / 分钟 |
| 建造一级城镇 / 兵营 / 要塞 | 80 / 100 / 100 金币 |
| 一级建筑施工时间 | 90 秒 |
| 首都基本兵力上限 | 200 |
| 一级兵营额外兵力上限 | 150 |

按这些初值，开局有 75 金币 / 分钟收入；全速招募消耗 18，120 兵的维护消耗 6，六格普通领土消耗 3，初始净收入约 48 金币 / 分钟。此计算仅检查初值自洽，并不是平衡性结论。

施工、升级和招募只有足够资金时进行。缺钱时先暂停招募和新建设；长期维持不了军队时逐步流失兵力，不得出现负金币维持无限军队。

## 6. 领土如何被攻占

### 下令

点选相邻目标，界面显示归属、可见驻军、地形、进攻来源、到达时间以及大致风险。选择投入兵力后下达命令。

进攻必须从实际可到达的己方部队出发，沿合法路线行军；目标必须与己方领土接壤。远方部队调来需要时间，同一批兵力不能同时驻守、行军和作战。

玩家可以选定一组相连的目标作为一次有限作战计划。执政官只能逐步执行，在预算不足、目标变强或路线失效时停止，不把一个目标扩展成无限征服命令。

### 行军、战斗与占领

1. 集结并出发：来源地区的驻军实际减少。
2. 行军：沿地图移动；路线变化、断供或敌人截断交通都会影响执行。
3. 接战：双方持续损失兵力；防守地形、要塞、军事质量和补给影响战力。
4. 撤退或攻破：玩家能撤退，剩余部队沿路线返回；没有瞬间取消并返还兵力。
5. 占领：守军被击退后，进攻方完成短暂占领过程；期间对方仍有反击机会。
6. 整合：新占城市暂时降低产出，稳定后恢复，不能攻下城市马上全额滚雪球。

空地扩张较快；弱 AI 冲突以一两分钟内看到结果为目标；玩家之间的有驻军战斗以数分钟为尺度；首都攻城通常更长。具体战斗公式和时长需模拟后锁定，不能只按总兵力大小瞬间判定归属。

界面使用“优势 / 接近 / 危险”和估计范围，明确估计不包括未来增援。第一版不同时加入严肃战争迷雾；战术信息以可见数据为主。

### 首都与灭国

首都有驻军、城防和占领过程，不能用一次点击立刻清空全国。

首都失守后，其他领土、城市和当地部队保留；核心管理与相关产出暂时受损。有城镇时可以选择迁都，迁都消耗金币和时间；执政官可按预先指定的备用城市执行迁都。

国家在所有可运行城市失守、没有合法恢复据点后灭亡。界面结算本次国家历史，记录存续时间、最大面积与代表事件。玩家经过建国冷却后在合适的边疆重新建立国家。

重建保留外观、称号和史册，不继承无限叠加的产出或军事优势。重新建国的保护和初始资源发放需有频率限制，不能借反复自灭刷资源。

## 7. 补给与大国压力

每块生产领土应能沿己方控制区域连接到首都。被切断时，生产和补员逐步下降，当地部队先消耗储备，再承受补给惩罚；不会因为断线一秒立刻消失。

远离首都的地区有额外治理成本。较高级城镇可承担区域治理，减轻距离成本，但仍必须保持与国家主体的连接。建立区域城市也需要时间、资源与防守。

大国主要面对：

- 更长的边境，需要更多实际驻军。
- 更远的交通，使增援不能及时到达所有方向。
- 更多占领中的城市，短期产出有限。
- 更高的治理和军队维护成本。
- 长期断供或无人经营的边疆可能出现自治势力。

这些规则提供小国赢得局部战斗的机会，并不承诺小国必胜。不会因为玩家排名第一就突然凭空给其军队减半，也不会因为别人较弱而直接赠送无限兵力。

## 8. 执政官 AI：玩家离线后的代理

执政官使用可解释的规则和目标选择，不要求调用外部大模型。它使用国家真实拥有的金币、部队与路线，遵守相同建设、行军和战争规则。

托管方针在在线时也可使用；离线不触发资源翻倍或特权。玩家上线可随时接管，但正在行军和战斗的命令仍需要合法撤回。

### 四种方针

| 方针 | 行为 | 默认是否主动攻击玩家 |
| --- | --- | --- |
| 守土 | 优先补充驻军、保护城市与恢复交通 | 否 |
| 发展 | 安排建设，保留必要防守兵力 | 否 |
| 扩张 | 寻找相邻空地与较弱 AI 地区 | 否 |
| 征战 | 执行玩家明确指定的玩家目标与路线 | 需明确开启 |

每种方针都有必要的自卫行为。主动攻打玩家是独立权限，不能因为玩家选择“扩张”而悄悄开启。

### 玩家能够设置的限制

- 金币最低储备，例如不低于 100。
- 国土防守兵力比例，例如至少保留 50%。
- 自动建设预算和优先方向。
- 自动进攻的对象范围。
- 一次作战最多投入多少兵力。
- 滚动 24 小时主动战争损失上限。
- 哪些地区必须优先守住，哪些地区可以放弃。
- 是否允许迁都，以及备用城市。

主动作战损失额度耗尽后停止新进攻并撤回可撤部队；正常自卫仍会继续。界面应解释该额度限制主动战争，不是保证国家不会因防守而遭受更多损失。

### 决策优先级

紧急守城与保护退路 → 保留储备 → 玩家指定计划 → 方针建设 → 可选扩张。

每个重要命令保存原因：“东侧兵力不足，调入 40 兵”“金币低于储备线，暂停招募”“预计损失超过额度，停止进攻”。玩家可以查看和调整，不能只收到模糊的“AI 已完成”。

系统不承诺离线无敌。长期无人干预的国家仍可能战败；目标是让离线玩家的预先安排有作用，让在线优势主要来自判断和及时调度。

## 9. 独立 AI 国家

AI 国家与玩家代理是不同角色，但遵守同一资源、维护、行军和占领规则。

| 类型 | 行为 | 给玩家的体验 |
| --- | --- | --- |
| 重建公社 | 发展生产、有限自卫、扩张克制 | 开局邻居与相对稳定的边界 |
| 铁律军团 | 重视要塞与通路，逐步推进 | 需要组织进攻的中期对手 |
| 游猎自治领 | 选择薄弱边境、小规模袭击 | 提醒玩家不能完全放空驻军 |

新手附近使用实力适合的 AI；高价值区域有更强守军。区别应来自经营和方针，不是凭空刷新无穷军队。

AI 数量补充低人数时的冲突密度。所有真人离线时世界仍运行，但独立 AI 的扩张目标有地区范围和维护压力，避免无人期间一个 AI 自动吞掉全部大陆。

新 AI 可以接管长期无人经营的自治地区或新开放区域，不能在玩家仍持有的领土上凭空出生。

## 10. 动态地图与出生算法

### 为什么不能只统计在线连接

关闭网页不等于国家不存在。离线托管中的国家仍占地，地图需求应参考近期活跃国家、现存领土、战线密度和可用出生区域。

不能因为打开多个标签页就扩图，也不能因为夜间在线人数下降就删除土地。

### 扩图规则

原型可以以“64 格公共缓冲 + 每个近期活跃国家约 36 格可用土地”作为容量参考，再根据出生空间和实际拥挤程度调整。参考面积不是玩家免费配额，不意味着给每个玩家保留私有安全区域。

1. 统计近期活跃的真实国家身份，托管国家在活跃保留期内计入需求。
2. 检查是否存在安全、能发展且靠近邻国的合法出生区。
3. 如果拥挤持续存在，开放一小块与现有战场相连的新区域。
4. 新区域带有地形、弱自治领、进攻通路和争夺目标。
5. 给开放设置冷却和面积限制，避免频繁进出或批量建国使地图暴涨。

长期无人边缘可在公告后逐步回收，但只处理没有国家持有、没有部队或战斗、没有有效通路依赖的地区。地图增长优先于缩小；第一版可以只开放区域，暂不实现边缘回收。

### 出生评分

候选区域必须容纳七格初始领地，不能覆盖现有国家。评分同时考虑：

- 附近至少有一个扩张方向。
- 不是最强国家首都或重兵集结区旁边。
- 与其他近期活跃国家距离适中。
- 有弱 AI 缓冲，但没有很长一段完全无人区域。
- 地形不能把新玩家封在只剩唯一死路的位置。

没有合格候选区域时，先开放受控边疆或等待腾出空间，不能直接塞进明显必败的位置。

### 防止长期躲在边缘

- 只能相邻扩张，迁都也只能迁至合法己方城市。
- 外缘开放后依然有自治势力和维护成本。
- 公共信标和较好的生产地区分布在有交通、有邻国的区域。
- 边疆越远，经营成本越高，不能同时拥有更安全且更高产出的最优位置。
- 后续出生区可布置在已开放且合法的边疆，使新边疆逐渐形成邻国。

世界内允许保守经营，但不能依靠地图机制获得永远没有邻国的私有角落。

## 11. 长期运行、历史与目标

世界与国家领土持续保存。战争、分裂、迁都和重建产生历史。每周“大陆纪事”只结算展示与称号，开始新的统计窗口，不能清空地图或已有国家。

目标分三层：

| 时间尺度 | 示例 |
| --- | --- |
| 几分钟 | 完成建筑、夺下一格、守住一次进攻 |
| 几小时 | 打通交通、争夺一座信标、击败一个邻国 |
| 长期 | 成为地区强国、保住国家、留下史册、重新建立一个更好的国家 |

公共信标提供有限的当地收益与历史计分，不赋予永久无限叠加的全国战力。首批信标位置随地形固定，让玩家能够围绕明确目标形成冲突。

榜单展示领土、经营、战争和历史等不同维度。大国有更多责任和更大曝光，但不通过强制重置让第一名消失。

连续很久没有真实玩家经营的国家进入衰退：停止主动入侵、逐步降低扩张能力，最终让未维护地区自治。原型可考虑 72 小时后进入衰退提示、7 天后开始外围自治；这些阈值必须向玩家公开。衰退不能被挂机刷新页面永久取消。

身份、旧国家记录和外观保留，土地与军队不永久冻结。这让空闲国家有退出过程，也给新人留下真实进入世界的空间。

## 12. 联机互动与第一版的边界

第一版允许观察邻国、交战、查看国家信息和使用简单的停战提议。停战如果上线，必须有明确范围与到期时间，约束双方的玩家命令和托管 AI。

联盟、多人外交、物资交易与自由聊天会增加围攻、刷资源和管理复杂度，放在核心玩法验证之后。第一版不开放直接赠送兵力与金币。

频繁建国、同一组国家反复互刷、受保护国家参与围攻、重连重复执行命令等应从规则层处理。身份和设备限制只是辅助，不能声称能够完全识别每个真人。作弊防护也不能只依靠隐藏按钮。

如果单服容量达到上限，需明确排队或观战；不能偷偷把朋友分进不同世界，再声称所有人在同一地图。

## 13. 页面与操作界面

地图占据主区域，外围采用网站已有主题与控件。

- 顶部：国名、金币及净增长、兵力及上限、连接状态。
- 地图：领土颜色、首都与建筑标记、局部驻军、行军路线、交战提示。
- 点选面板：当前格信息与主要操作；只出现此格真正可用的建设、调兵、进攻或撤退。
- 执政官按钮：方针、储备和进攻权限；保存前显示哪些行为因此允许发生。
- 战报按钮：回归摘要、重要事件与完整记录。
- 全球视图：全图归属；放大后查看建筑和部队。第一版数据透明，战争迷雾后置。

移动端点选后从底部显示操作，拖动地图不触发进攻；危险操作需要明确目标和投入数值。键盘焦点、按钮禁用原因与错误反馈均要可见。

### 回归战报示例

“你离开了 3 小时。执政官完成 2 项升级，守住东侧城镇，放弃了西北 1 格。金币净增加 420，兵力净减少 26。当前东侧仍在交战。”

示例数据仅用于说明信息结构。战报来自实际世界事件及离线前后状态，不通过随机构造“离线收益”。关键事件可点选并定位到对应地区；没有事件时明确显示正常发展。

地图采用清晰的地形与国家标记，避免只靠颜色区分敌我。Soft UI 外围沿用浅蓝、柔和阴影与克制柔光；Liquid Glass 外围沿用浅色网格、玻璃面板和可读文字。两套主题共用布局，游戏土地颜色不被面板滤镜扭曲。

建筑完成、旗帜和行军可有少量动态效果；装饰支持减少动态效果，页面不可见时停止绘制，世界由服务器继续运行。

## 14. 一段具体的游玩故事

你建立“青岚领”，位于丘陵西侧，拥有首都、城镇和兵营。东边是重建公社，北边是另一个刚建立的玩家国家，南方山口通向信标遗迹。

你先加建城镇，再派部队拿下东边弱 AI 的两格土地。收入上升，同时边境变长。你把主力留在南侧，北侧只安排足以拖延进攻的驻军。

保护结束后，北方邻国争夺同一条通路。你没有把所有兵力投入正面，而是占领一块连接其前线的土地，使其增援绕路。对方暂停进攻，你夺得通路，却在另一侧丢了一格。

离开前，你把方针设为“发展”，保留一半兵力守城，指定南方山口必须守住，并禁止主动攻打玩家。

回来时，执政官已经升级了城镇，抵挡一次北方进攻。它没有追击，因为追击会超过你设置的作战限制。你通过战报定位交战地区，决定集中兵力争夺山口。

几天之后，你的国家可能扩张成地区强国，也可能因多线战争失去首都。即使旧国灭亡，史册仍会记录它；你可以在新的边疆重建，而不是带着无限属性重新碾压新人。

这段故事是设计情景，不是当前可玩功能。

## 15. 技术落点与真实联机要求

继续使用项目现有原生 HTML / CSS / JavaScript Hash SPA。二维地图可用 Canvas；外围采用现有公共组件。无需为这款游戏重建整个网站。

新增一个持续运行的世界模拟模块、实时连接层和持久化层。无论最终选用哪种实时库，都需要保证：

- 服务器掌握真实状态，校验每条建造、调兵和进攻命令。
- 客户端提交意图，不能直接提交可信的金币、军队或领土结果。
- 生产、战斗、行军和 AI 在服务器运行；没人开网页时也继续运行。
- 身份跨连接保持，重连不重复建国、不重复扣费、不重复执行同一命令。
- 保存地图种子、地形、归属、国家、建筑、部队位置与订单、方针、计时与重要事件。
- 使用一致的世界版本、持久化快照和命令记录，处理重启后的恢复。
- 服务器停机与玩家离线分别处理：玩家离线继续模拟；服务器停机采用公开的世界暂停规则，不能重启后跳过战争却发放大量经济收益。
- 初期一个逻辑世界由一个明确的模拟权威维护。容量增长时再研究分区，不以多份独立状态假装共享大陆。

原型可尝试一秒一个模拟步、数次每秒的状态增量广播，客户端独立平滑绘制。模拟频率、单服人数和地图上限要通过测量确定，不能先承诺支持成千上万人。

页面正式接入时，需要模板、页面注册、游戏卡片与 `mount / unmount`，声明 `navSection: "games"`；切页关闭本页连接和渲染，国家托管继续在服务器运行。实现后再把已验证能力写入 README，不能现在写成已上线。

## 16. 实现阶段

### 第一阶段：真正可玩的核心

- 一个共享持久世界，二维六边形地图。
- 金币、兵力，两种核心资源；四类主建筑。
- 建设、升级、驻军、合法行军、相邻进攻、撤退、占领与迁都。
- 基础补给、维护和断供反馈。
- 可恢复身份、新手保护、出生评分、灭国与重建。
- 少量独立 AI 国家。
- 守土、发展、有限扩张方针；玩家可指定有限作战目标。
- 回归战报、实时同步、断线重连和世界存档。
- 基础受控扩图；第一版不缩小已开放地图。
- 网站入口、双主题、桌面与窄屏。

上述是一个完整可玩版本，不应把“能显示彩色地图”当作联机游戏完成。

### 第二阶段：让长期世界更有故事

- 更完整的主动征战权限与预算。
- 不同 AI 方针、区域治理与长期自治。
- 公共信标、大陆纪事与可定位的历史事件。
- 停战与简单外交。

### 第三阶段：有实际需求后增加

- 联盟与更多多人关系。
- 战争迷雾、更加丰富的地形或兵种。
- 经验证的单世界分区与性能扩展。
- 外观和史册展示；任何付费方案均不售卖永久战力。

## 17. 开发前与发布前如何验证

### 平衡模拟

用可重复的国家与 AI 场景检查：新国家进入老世界、少数人在线、多数人离线、大国多线作战、所有真人离线、长期无人经营、扩图后人口回落。

记录首次有效操作、首次接壤、首次玩家交战、规模与存活时间、断供发生率、AI 主动损失、空闲国家占地和地区拥挤程度。调参依据这些结果，而不是只看地图动画。

出生规则至少通过“有可发展空间、不会覆盖现有国家、有合理邻国、失败时可等待或受控扩图”四项约束；长期平衡观察是否总是同一个初始国家吞并全部大陆。具体目标百分比需先有样本。

### 真实联机验收

- 两个独立浏览器身份进入同一地图，双方看到相同的归属和战斗结果。
- 一方建造、调兵或攻占，另一方收到真实结果。
- 关闭某玩家所有网页，执政官继续经营；再次进入能恢复同一个国家。
- 连续断线重连与重复命令不重复扣费或产生兵力。
- 重启世界服务后，存档、订单、方针和计时恢复一致。
- 无效、越权、超额和保护期禁止的命令由服务器拒绝。
- 扩图不移动已有国家，不覆盖领土；夜间人数下降不删除离线国家。
- 军队在驻守、行军、战斗和撤退间守恒，损失与招募有真实记录。
- 两套主题下检查真实操作、错误、禁用、选中、焦点、地图拖动与窄屏。
- 原站其他功能与导航正常，按 README 运行相关回归测试。

## 18. 设计底线

玩家需要真实地感觉到：建设改变产出，部署改变战局，托管执行自己的方针，别人的国家与自己共用一个世界。

不能用随机战报、客户端伪造 AI 对手、互不相通的房间或只展示增长数字替代这些体验。也不能用无限属性和地图无限摊大解决长期平衡。

后续调整应围绕已经明确的核心：有限大陆、持续世界、邻近发展、真实争夺、可解释托管，以及失败后仍能参与。
