# 手机端性能与兼容修复（2026-11-04）

## 已修改

- 手机与小屏不再显示全局 AI 助手，首次进入不下载助手、客户端及彩蛋脚本。DeepSeek 独立聊天工具保留。电脑从窄窗口恢复宽窗口时可按需初始化助手。
- Soft UI 手机端使用原有紫青柔光的静态 CSS 背景，不创建全屏原生 DPR 的 WebGL 背景。电脑切换到小屏会销毁背景渲染器，将背景画布缩至 1×1；恢复宽屏可重新创建。
- 小屏停止魔方自动散开与待机旋转、滚动渐入、全页退出与主题遮罩动效，保留手动转动和面按钮。魔方不在可见区域时暂停，卸载释放观察器。
- Liquid Glass 保留网格、半透明填色、玻璃边缘高光和阴影；小屏不再逐卡片常驻 `will-change`，取消固定背景滚动采样和播放器背景模糊。二维码、图片混淆待机画布在手机上静态展示，桌面离屏或后台停止；抽奖灯泡、光晕和当日发售徽章在手机上静态显示。
- 手机播放器改为 144×56 的底部横向条，播放、下一首与展开可直接点击；展开后歌曲、进度、上一首、下一首和歌单保持可用。操作区留出底部安全区，并修复原先 100vw 在有滚动条时超出可见区域的问题。
- 贪吃蛇增加方向按钮，处理取消滑动，修复倍速控件裁切、棋盘宽高比例失真和进入页面自动滚动。小屏画布按实际可用宽度绘制，不再沿用最小 560px 的桌面缓冲区。待机和暂停停止绘制；移出可见区域或进入后台自动暂停，主动继续后恢复。移动端运行绘制上限为 30 次/秒。
- 台球收到系统取消触控或丢失指针捕获时取消瞄准，不再误击球。台球、贪吃蛇、Only Up 和深渊协议的小屏画布 DPR 上限为 1.5，不修改物理或战斗规则。
- 修复 Liquid Glass 的通用叠层选择器覆盖 ASCII、图片像素化上传输入框的绝对定位；上传框恢复覆盖区域并提供焦点边框。
- 图片像素化增加读取/解码失败反馈，换文件和卸载取消旧读取、丢弃过期结果、释放旧画布与图片引用，避免旧任务回写到后来打开的页面。
- Lens 预览沿用共享样式，并同步必要的外壳副本和助手加载条件，保留存储隔离。

## 设备提示

策略位于共享登记表 `page-registry.js` 的 `mobile` 字段，由路由处理。没有新增独立路由白名单。

| 页面 | 手机端行为 |
| --- | --- |
| DOOM、字符城市 | 弹窗建议电脑打开；保留介绍、帮助和返回分类入口，不加载键鼠游戏脚本或引擎 |
| 拼豆工坊 | 提示逐格精修、图层操作更适合电脑；主动选择继续后加载工具 |
| 视频转 GIF | 提示裁剪、编码占用内存；主动选择继续后加载工具 |
| 其他页面 | 正常进入，使用相应手机布局 |

提示采用原生 dialog，键盘焦点留在弹窗内；Esc 或关闭按钮返回可操作的介绍面板。切页清理弹窗和监听，已开始下载的推荐工具在离开页面后不会挂载到新页面。旧 Hash 和城市别名先解析到正式页面，再采用同一策略。

## 生效与边界

本轮仅修改本地仓库，未推送或部署。上线需要同步修改的前端、登记表、必要的 Lens 副本与新增的 `css/mobile.css`、`js/device-support.js`，重启 Node 服务以刷新服务端登记表；内容版本地址由现有机制自动更新。部署后按 README 对正式站点再次执行 SEO 验证。

本轮浏览器为 Windows 内置浏览器，窄视口检查不等于真实 Android / iOS 手机测试。没有实测低配手机 GPU、发热、耗电、iOS 软键盘和浏览器下载面板，也没有完成所有游戏的全程游玩。不据桌面测试宣称手机帧率提升百分比或保证所有机型不再卡顿。
